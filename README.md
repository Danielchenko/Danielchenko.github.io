# Daniel Carvalho · Portfólio

Site pessoal de Daniel Carvalho, Software Engineer full-stack.

**🔗 [danielchenko.github.io](https://danielchenko.github.io)**

## Tecnologias

- HTML, CSS e JavaScript puros, sem build e sem framework
- [GSAP](https://gsap.com) 3.13 com ScrollTrigger, ScrollSmoother, SplitText e ScrambleText para as animações
- Tema claro e escuro, layout responsivo e respeito à preferência de "reduzir movimento" do sistema

## Estrutura

```
├── index.html       conteúdo
├── css/style.css    estilos, temas e responsivo
├── js/main.js       tema e animações
└── assets/          foto e favicon
```

## Rodando localmente

Basta abrir o `index.html` no navegador.
